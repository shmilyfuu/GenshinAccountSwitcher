原神账号切换器 - C++ / WinUI 3 原生重构版

当前开发基线：
- C++20
- WinUI 3 / Windows App SDK 1.7（已在目标机器验证启动；后续迁移到受支持版本）
- x64
- 未打包、框架依赖
- 无 .NET
- data 目录位于 EXE 同目录

当前已迁移：
- 暗色 WinUI 3 界面
- 当前注册表登录态读取
- UID 识别
- 已保存账号元数据
- DPAPI 凭据加密
- 添加 / 更新 / 重命名 / 删除
- 账号切换与写回校验
- 切换前恢复快照
- 游戏进程检测
- 游戏路径自动检测 / 手动指定
- 切换并启动原神
- UID 命中但 ADL 变化时仍识别为已保存账号，并提示更新登录态

安全边界：
- 不联网
- 不上传账号数据
- 不记录原始登录凭据
- 不需要管理员权限
